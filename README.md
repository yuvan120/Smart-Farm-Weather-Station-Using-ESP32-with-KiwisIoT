#  Smart Farm Weather Station Using ESP32 with KiwisIoT

## 📌 About the Project

Smart Farm Weather Station Using ESP32 with KiwisIoT is an IoT-based project designed to monitor real-time weather and environmental conditions for agricultural applications.

Using the ESP32 microcontroller and connected sensors, this project collects important weather information such as temperature, humidity, atmospheric pressure, and rainfall (depending on the sensors used).

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where farmers and users can visualize and monitor weather conditions through an online dashboard from anywhere.

This project helps farmers understand environmental changes, make better farming decisions, and demonstrates how IoT technology can support smart agriculture.
